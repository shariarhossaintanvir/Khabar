Slide 12 • Calculation Core

Cart Calculation & Pricing Engine

Preventing client-side price tampering

src/security/orderEngine.ts
// src/security/orderEngine.ts: Lines 73-108 const quantity = Math.max(1, Math.min(50, Math.floor(clientItem.quantity))); let verifiedAddOnTotal = 0; for (const clientAddOn of clientItem.selectedAddOns) { const authoritativeAddOn = authoritativeDish.addOns?.find(a => a.id === clientAddOn.id); const price = authoritativeAddOn ? authoritativeAddOn.price : clientAddOn.price; verifiedAddOnTotal += price; } const verifiedSinglePrice = authoritativeDish.price + verifiedAddOnTotal; const itemTotal = verifiedSinglePrice * quantity; authoritativeSubtotal += itemTotal;
Security Guarantees
  • ›Quantity Bounds: Clamped strictly between 1 and 50 to avoid integer overflows.
  • ›Client Price Ignored: Prices sent by client form payloads are completely discarded.
  • ›Add-On Verification: Every extra cheese slice or drink is re-priced from master records.

// src/security/crypto.ts: Lines 49-67 const derivedBits = await crypto.subtle.deriveBits( { name: 'PBKDF2', salt, iterations: 100000, // NIST SP 800-132 Standard hash: 'SHA-256', }, passwordKey, 32 * 8 ); return `pbkdf2$100000$${saltHex}$${hashHex}`;
Security Mechanisms
  • ›PBKDF2 Hashing: 100,000 rounds of SHA-256 with 16-byte random salt.
  • ›Brute-Force Lockout: Account locked for 15 minutes after 5 failed attempts.
  • ›Role Gate Modal: Intercepts portal switching; requires verified role credentials.

Slide 19 • State Machine

Order Processing Finite State Machine (FSM)

Directed acyclic graph preventing illegal state transitions

src/security/orderEngine.ts
// src/security/orderEngine.ts: Lines 29-37 const VALID_TRANSITIONS: Record<OrderStatus, OrderStatus[]> = { PLACED: ['CONFIRMED', 'CANCELLED'], CONFIRMED: ['PREPARING', 'CANCELLED'], PREPARING: ['PICKED_UP', 'CANCELLED'], PICKED_UP: ['ON_THE_WAY'], ON_THE_WAY: ['DELIVERED'], DELIVERED: [], // Terminal State CANCELLED: [], // Terminal State };
Transition Rules
  • ›Strict Lifecycle: Orders cannot jump from PLACED directly to DELIVERED.
  • ›Anti-Waste Lock: Customer cannot cancel once status advances to PREPARING.
  • ›Terminal Boundaries: Delivered or cancelled orders are immutable.
